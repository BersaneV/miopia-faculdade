INÍCIO RÁPIDO
-------------

WINDOWS
  1. Instale o Python 3.10 ou mais novo: https://www.python.org/downloads/
     IMPORTANTE: na primeira tela do instalador, marque a caixinha
     "Add python.exe to PATH".
  2. Descompacte este .zip em uma pasta (ex.: C:\Miopia).
     Não rode de dentro do .zip — extraia primeiro.
  3. Dê DUPLO CLIQUE em  rodar.bat
     (na primeira vez ele cria o ambiente virtual e instala o pygame;
      pode levar de 1 a 2 minutos e precisa de internet).
  4. O jogo abre. Para sair: Esc no menu ou feche a janela.

  Se o duplo clique não funcionar, abra o "Prompt de Comando" (cmd),
  entre na pasta do jogo e rode:
      python -m pip install pygame-ce
      python src\main.py

MACOS / LINUX
  Abra o Terminal e rode:
      cd caminho/da/pasta/Miopia
      python3 -m venv .venv
      source .venv/bin/activate
      pip install -r requirements.txt
      python src/main.py

  (ou simplesmente:  ./rodar.sh )


CONTROLES
---------
  WASD ou setas ....... voar
  Shift ............... correr (gasta luz e faz barulho)
  Espaço .............. clarão de luz (afasta e cega inimigos)
  P ou Esc ............ pausa
  R (na pausa) ........ reiniciar
  V (na pausa) ........ voltar ao menu
  M ................... som ligado/desligado
  - e + ............... volume
  F11 ................. tela cheia (imagem suavizada, proporção mantida)
  Setas + Enter ....... navegar nos menus
  A / D (no menu) ..... dificuldade (Fácil / Normal / Difícil)
  Espaço / clique ..... avançar cutscene
  Esc (na cutscene) ... pular a cena


DOIS MODOS DE JOGAR
-------------------
  História .. O MODO PRINCIPAL. Quatro fases emolduradas por cutscenes:
              prólogo em 3 cenas, uma mensagem ambiental + pergunta de
              compreensão e uma cena ao entrar em cada fase, e o desfecho
              (vitória ou derrota) antes da tela final.
              Espaço avança a cutscene, Esc pula. Nada é obrigatório.

  Infinito .. "AS FASES QUE NÃO ACABAM". O Breu sonha e a mata se refaz:
              as fases emendam sem cutscene e sem tela no meio (só um
              aviso curto no topo) e NÃO repetem a história:
              cada fase é nova, com nome próprio, e entra com mais
              inimigos que a anterior, pede mais orvalho e dá menos
              fôlego. NÃO tem chefe: a Coruja é só da história.
              O relógio não tem teto e o amanhecer nunca chega:
              a partida acaba quando as três fagulhas se apagam.
              O menu guarda quantas fases você alcançou.


AS QUATRO FASES
--------------
  Fase 1 · Clareira            -> Bosque das Samambaias
  Fase 2 · Trilha interrompida -> Córrego Fundo
  Fase 3 · Borda da floresta   -> Taquaral
  Fase 4 · Último refúgio      -> Gruta da Figueira

  No fim de cada fase aparece a MENSAGEM AMBIENTAL daquele trecho e uma
  pergunta sobre ela (ODS 15 e ODS 4). A pergunta é obrigatória, mas
  errar não tira vida, ponto nem progresso: o jogo mostra a resposta
  certa e explica. Responda com as setas e Enter, ou com 1, 2 e 3.


CHEFE (FASE 4) — A CORUJA
--------------------------
  No último trecho, a Coruja guarda a entrada da gruta. Ela está cega e
  caça pelo SOM: correr faz barulho, andar devagar não.
  Ela avisa antes de atacar (um "!" pisca em cima dela).
  Dê 3 clarões (Espaço) perto dela: a barra no topo enche e ela se
  acalma — o caminho abre e você ganha +500 pontos.

  O clarão gasta luz. Colete orvalho antes de chegar perto dela.


MÚSICA
------
  Cada fase tem a sua trilha: bosque (doce), córrego (água), taquaral
  (tenso) e gruta (grave). No modo infinito elas se revezam conforme o
  cenário de cada fase. M liga/desliga e - / + ajustam o volume.


OBJETIVO
--------
  Coletar o orvalho de cada fase e voar até a colônia antes do
  amanhecer. A sua luz é a visão, o combustível e a arma: ela diminui
  a cada segundo. Quatro fases até reencontrar a colônia.


PROBLEMAS COMUNS
----------------
  "python não é reconhecido"
      -> Reinstale o Python marcando "Add python.exe to PATH",
         ou use  py src\main.py  no Windows.

  "No module named 'pygame'"
      -> pip install pygame-ce
         (use o MESMO Python que roda o jogo; com venv, ative antes).

  "Não aparece janela" / erro de display no Linux ou WSL
      -> o jogo precisa de ambiente gráfico. No WSL, rode no Windows
         ou instale um servidor gráfico. Em Linux comum:
         sudo apt install python3-tk libsdl2-2.0-0

  Sem som
      -> o jogo funciona em silêncio; verifique o volume do sistema
         e aperte M dentro do jogo.

  Antivírus reclamando do rodar.bat
      -> é só um atalho de texto; abra com o Bloco de Notas para
         conferir. Alternativa: use os comandos do Prompt acima.
